# 사용자 피드백 기록

배포된 외출톡 (AI Outing Talk)을 실제 사용자가 사용한 뒤 받은 피드백과 개선 반영 내역을 기록한다.

## 1. 테스트 개요

| 항목 | 내용 |
|---|---|
| 테스트 일자 | 2026-11-__ |
| 참여 인원 | __명 (과제 요건 5명 이상) |
| 테스트 대상 | https://ai-outing-talk.onrender.com/ |
| 사용 환경 | 모바일, PC |
| 소요 시간 | 1인당 10분 내외 (알림 수신 대기 시간 제외) |
| 수집 방식 | 질문지를 전달하고 텍스트로 답변을 받음 |

## 2. 질문 항목

1. 동의, 로그인, 알림 등록까지 진행하는 데 어려운 점이 있었는가.
2. 입력한 문장을 서비스가 의도대로 해석했는가. (입력 문장과 해석된 출발지·도착지·시각)
3. 알림 목록 화면에서 알림 내용과 상태를 이해할 수 있었는가.
4. 카카오톡 알림을 받았는가. 받은 시각과 문구는 적절했는가.
5. 불편했던 점이나 추가로 필요한 기능은 무엇인가.
6. 다시 사용할 의향이 있는가. (1~5점과 이유)

## 5. 개인정보 안내

- 테스트 참여자에게 수집 항목과 이용 목적을 사전에 안내하고 동의를 받는다.
- 기록에는 참여자의 실명과 연락처를 남기지 않고 식별 기호(사용자 A, B, C)를 사용한다.
- 카카오 계정 이메일은 테스트 계정 등록 목적으로만 사용하고 이 문서에는 기록하지 않는다.
