# 사용자 테스트 피드백 기록

## 1. 테스트 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2026년 11월 23일 ~ 11월 24일 |
| 참여 인원 | 6명 |
| 방식 | 배포된 서비스(https://ai-outing-talk.onrender.com/)를 직접 사용한 뒤 질문지에 응답 |
| 수집 경로 | 카카오톡, 이메일 |
| 기록 원칙 | 참여자의 실명과 연락처는 기록하지 않고 식별 기호(사용자 A~F)로만 표기 |

테스트 도중인 11월 23일 밤, 1차 피드백을 반영한 개선 사항이 배포되었다.
사용자 A·B·C는 개선 전 화면으로, 사용자 D·E·F는 개선 후 화면으로 테스트했다.

## 2. 질문 항목

1. 동의 화면부터 로그인, 알림 등록까지 가면서 막히거나 헷갈린 곳이 있었나요?
2. 입력한 문장을 서비스가 제대로 알아들었나요?
3. 알림 목록 화면의 내용이 이해되셨나요?
4. 카카오톡 알림을 받으셨나요? 받은 시점과 문구는 어떠셨나요?
5. 불편했던 점이나 있으면 좋겠다 싶은 기능이 있나요?
6. 실제로 쓰실 것 같나요? 1~5점과 이유 한 줄 부탁드려요.

### 3-2. 결과 요약

| 항목 | 결과 |
|---|---|
| 참여 인원 | 6명 |

**공통 지적**

- 알림 문구의 시점 표현이 모호함 (A)
- 출발 권장 시각이 화면에 표시되지 않거나 촉박함 (B, D, E)
- 알림 수정 기능 부재 (A, D, E) — 최다 요청
- 안내와 예시 문구 부족 (B, D, E)
- 기존 방식 대비 차별점이 부족함 (E, F)

마지막 항목은 기능 결함이 아니라 서비스의 가치 제안에 대한 지적이다.
사용자 F는 "검색하는 것과 알림을 설정하는 것이 비슷한 일이라 이중으로
일하는 느낌"이라고 했고, 사용자 E는 "현재 쓰는 캘린더와 차별점이 부족하다"고
했다. 사용자 E는 도착지 주소가 함께 제공되면 재사용 의향이 2점에서 5점으로
오른다고 밝혔다.

**미수신 원인**

테스트 중 확인된 두 가지 원인은 모두 기능 결함이 아니라 안내 부족이었다.

1. 날씨 조건을 포함해 등록하면 조건을 충족할 때만 발송된다. 사용자 D가 조건을 제외하고 재등록해 정상 수신을 확인했다.
2. '나와의 채팅'으로 전달되는 메시지는 알림음 없이 읽음 상태로 도착해 놓치기 쉽다. 사용자 E가 지적했다.

**신규 결함**

조건에 따라 다른 문구를 요청하는 입력("~이상이면 A, 미만이면 B")에서 오류가 발생한다.

## 5. 개인정보 안내

- 테스트 참여자의 실명, 연락처, 카카오 계정 정보는 수집하거나 기록하지 않았다.
- 응답 내용은 식별 기호(사용자 A~F)로만 정리했다.
- 참여자에게 테스트 목적과 응답의 과제 제출 활용 사실을 사전에 안내하고 동의를 받았다.
- 서비스는 카카오 로그인 시 동의 항목을 표시하며, 수집한 정보는 알림 발송 목적으로만 사용한다.
