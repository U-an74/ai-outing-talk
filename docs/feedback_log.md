# 사용자 피드백 기록

배포된 외출톡 (AI Outing Talk)을 실제 사용자가 사용한 뒤 받은 피드백과 개선 반영 내역을 기록한다.

## 1. 테스트 개요

| 항목 | 내용 |
|---|---|
| 테스트 일자 | 확인 필요 |
| 참여 인원 | 확인 필요 (5명 이상 목표) |
| 사용 환경 | 모바일, PC |
| 소요 시간 | 1인당 10분 내외 |

## 2. 질문 항목

1. 외출 계획을 문장으로 입력할 때 어려운 점이 있었는가.
2. 알려준 출발 시각이 납득할 만했는가.
3. 알려준 준비물이 도움이 되었는가.
4. 카카오톡 알림을 받은 시점이 적절했는가.
5. 다시 사용할 의향이 있는가. 그 이유는 무엇인가.
6. 개선이 필요하다고 느낀 점은 무엇인가.
