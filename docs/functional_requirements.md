### 4-3. 외부 API 연동 구조

1) 카카오 로그인 및 메시지 연동

- 인증 방식: OAuth 2.0
- 로그인 제공자: Kakao
- Redirect URI (로컬 개발 환경): `http://localhost:8000/api/auth/kakao/callback`
- 인증 정보: Access Token 및 Refresh Token
- 메시지 전송 방식: 카카오톡 나에게 보내기 API
- 메시지 전송 동의항목: `talk_message`

※ 실제 배포 시 배포 서버 주소에 맞는 Redirect URI 별도 등록 필요

2) 카카오 토큰 관리

- Access Token 발급 및 갱신
- Refresh Token을 활용한 인증 유지
- 사용자별 토큰 저장 및 관리는 Firestore 연동 예정

### 4-5. 기술적 의사결정 및 검토 사항
1) 카카오톡 알림 발송 방식 선정

    - **검토 대상**
        - [방식1] 카카오톡 채널을 통한 사용자 알림 발송
        - [방식2] 카카오톡 메시지 API를 통한 사용자 본인에게 메시지 발송

    - **최종 결정**
        - 카카오톡 메시지 API의 '나에게 보내기' 기능을 활용하여 각 사용자가 본인의 카카오톡으로 외출 알림을 받는 방식으로 결정하였다.

    - **선정 이유**
        - 카카오톡 채널을 통한 메시지 발송은 별도의 비즈메시지 연동 및 권한 확보가 필요
        - 마감 내 MVP 구현 가능성과 API 접근성 고려
        - 사용자별 카카오 로그인 및 메시지 발송 동의를 통한 알림 전달 가능

    - **추후 검토 사항**
        - Firestore 기반 사용자별 토큰 저장 및 관리
        - 토큰 만료 시 자동 갱신 처리
        - 예약 시간에 따른 자동 메시지 발송 연동
        - API 이용 제한 및 메시지 발송 정책 확인
        - 채널 발송 방식의 추가 도입 필요성
