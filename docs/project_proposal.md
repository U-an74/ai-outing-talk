# 프로젝트 기획서

외출톡 (AI Outing Talk) - AI 기반 외출 알림 서비스

사용자가 외출 계획을 평소 말하듯 입력하면, AI가 날씨와 이동 시간을 확인해 출발 시각과 챙길 것을 판단하고 정해진 시각에 카카오톡으로 알려주는 서비스.

## 1. 문제 정의

- 약속 시간에 맞춰 나가려면 날씨, 교통 상황, 준비물을 각각 따로 확인해야 한다.
- 확인했더라도 출발 시각을 놓치면 소용이 없다.
- 기존 날씨 앱과 지도 앱은 정보를 보여줄 뿐, 사용자의 일정에 맞춰 먼저 알려주지 않는다.

해결 방향

- 입력은 자연어 한 문장으로 끝낸다. 항목을 하나씩 고르는 과정을 없앤다.
- 흩어진 정보를 AI가 모아 하나의 결론(출발 시각, 준비물)으로 만든다.
- 사용자가 앱을 다시 열지 않아도 지정된 시각에 카카오톡으로 먼저 알린다.

## 2. 타겟 사용자

- 약속이나 출퇴근 때문에 매일 출발 시각을 신경 쓰는 사람
- 우산, 겉옷 같은 준비물을 자주 잊는 사람
- 별도 앱 설치 없이 카카오톡으로 알림을 받고 싶은 사람

## 3. 핵심 AI 활용 방식

| 단계 | AI의 역할 |
|---|---|
| 입력 해석 | 사용자의 문장에서 출발지, 도착지, 도착 시각을 추출해 구조화된 데이터로 변환 |
| 도구 활용 | 날씨 조회와 이동 시간 조회 결과를 입력으로 받음 |
| 판단 | 조회 결과를 종합해 출발 시각과 준비물을 결정. 규칙만으로 다루기 어려운 조합(비와 교통 지연이 겹치는 경우 등)을 함께 설명 |
| 메시지 생성 | 사용자가 읽을 알림 문구를 생성 |

AI가 빠지면 사용자가 직접 날씨를 확인하고 출발 시각을 계산해야 한다. 서비스의 핵심 가치가 성립하지 않는다.

## 4. 기술적 접근 방식

### 처리 흐름

1. 사용자가 외출 계획을 자연어로 입력한다.
2. AI가 입력 문장을 구조화된 데이터로 변환한다.
3. 시스템이 날씨 정보와 이동 시간을 조회한다.
4. AI가 조회 결과를 바탕으로 출발 시각과 준비물을 판단한다.
5. 판단 결과를 데이터베이스에 저장한다.
6. 자동화 워크플로우가 알림 시각을 감시한다.
7. 지정 시각에 카카오톡 메시지를 발송한다.

### 기술 스택과 선정 이유

| 구분 | 기술 | 선정 이유 |
|---|---|---|
| 백엔드 | FastAPI (Python) | 팀이 학습한 언어이며, API 문서가 자동 생성되어 프론트엔드 연동 확인이 빠름 |
| 프론트엔드 | HTML, CSS, JavaScript | 별도 빌드 과정 없이 배포가 가능해 짧은 일정에 적합 |
| 데이터베이스 | Firebase Firestore | 서버 구축 없이 사용할 수 있고 무료 범위 안에서 운영 가능 |
| AI | 확인 필요 (LLM API) | 자연어 해석과 판단을 담당 |
| 외부 API | 기상청 단기예보, 카카오 Local, 카카오 Mobility | 날씨와 이동 시간 조회 |
| 메시지 발송 | 카카오톡 메시지 API | 사용자가 이미 쓰는 메신저로 알림을 전달 |
| 자동화 | n8n | 지정 시각 발송을 코드 없이 구성하고 실행 기록을 확인 가능 |
| 배포 | 확인 필요 | 외부에서 접속 가능한 환경 |
| 협업 | Git, GitHub | 브랜치와 PR 기반 리뷰로 변경 이력 관리 |

## 6. 개인정보 처리

- 수집 항목: 로그인 식별 정보, 사용자가 입력한 출발지와 도착지, 알림 시각
- 이용 목적: 알림 생성과 발송
- 보관 기간: 확인 필요
- 수집 시점에 동의 절차를 화면에 표시한다.
- 사용자 테스트 기록에는 참여자의 실명 대신 식별 기호를 사용한다.
